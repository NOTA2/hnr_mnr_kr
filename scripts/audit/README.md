- Some audit outputs are referenced by cleanup and QA docs. Treat audit scripts
  as active until the corresponding reports are either regenerated by a new path
  or marked historical.

  `analysis/generated_workbenches/translation_consistency/` QA evidence.

  text/image apply prerequisites, current review ROM paths, and BPS patch
  generation.
