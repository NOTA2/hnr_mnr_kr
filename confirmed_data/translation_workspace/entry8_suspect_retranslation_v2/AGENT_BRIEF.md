# Entry8 Suspect Part Full Retranslation Brief

이 작업은 기존 번역을 살짝 고치는 작업이 아니다. 의심되는 Entry8 파트를 원문과 문맥 기준으로 다시 번역한다.

반드시 함께 읽을 문서:

- `docs/translation_team/fma_translation_team_common_final_v4_1.md`
- `docs/translation_team/fma_translation_agent_final_v4_1.md`
- `docs/translation_team/fma_review_agent_final_v4_1.md`
- `docs/repeat_mistake_prevention.md`

## 절대 규칙

1. `manual_locked=true` 항목은 입력에서 제외되어 있으며, 어떤 경우에도 건드리지 않는다.
2. Entry8 fixed/in-place 항목은 `max_korean_chars` / `char_count` 기준으로 맞춘다. UTF-8 byte 길이를 이유로 과도하게 축약하지 않는다.
3. 허용 글자 수를 최대한 활용해서 자연스러운 한국어로 번역한다. “짧게만” 쓰지 말고, 의미/말투/조사/목적어/띄어쓰기를 최대한 살린다.
4. Entry8에서는 반각 공백을 쓰지 않는다. 띄어쓰기는 전각 공백 `　`만 쓴다.
5. 허용 글자 수 안에 들어간다면 전각 공백을 적극적으로 사용한다. 예: `솔링사건도아닌가` -> `솔링　사건도　아닌가`.
6. 원문에 있는 문장부호와 특수기호는 띄어쓰기 목적 외에는 임의로 제거하지 않는다. `、`, `。`, `！`, `？`, `…`, `「」`, `『』`, 괄호, 번호 기호 등은 가능하면 원문 형태를 보존한다.
7. 문장부호 바로 다음에는 공백을 넣지 않는다. 예: `아、　그래` 금지, `아、그래` 또는 의미상 필요하면 `아、그래　맞아`처럼 쓴다.
8. 일본어/한자가 번역문에 남으면 안 된다. 단, 원문 특수기호 자체는 일본어 잔존으로 보지 않는다.
9. 고유명사 내부를 쪼개지 않는다. 예: `코넬로`, `레돈드`, `솔링`, `다이무라`, `마틴스`, `호크아이`, `브래드레이`, `윈리`, `코니슈`, `링커`, `리젠블`, `리올`, `센트럴`, `이스트`, `키메라`, `오토메일`.
10. 계급/직책은 자연스럽게 띄어 쓴다. 예: `마틴스　중령`, `머스탱　대령`, `호크아이　중위`.
11. 공통 용어를 따른다. 예: `錬成=연성`, `国家錬金術師=국가　연금술사`, `賢者の石=현자의　돌`, `機械鎧=오토메일`, `合成獣=키메라`.
12. 번역문을 기존 현재 번역문에 맞추려고 하지 않는다. `source`, 주변 문맥, 공통 지침서를 보고 새로 판단한다.
13. 기존 번역이 의미를 누락했거나 띄어쓰기가 엉망이면 고친다. 기존 번역이 좋아도 원문 특수기호가 빠져 있고 들어갈 공간이 있으면 복원한다.
14. `max_korean_chars`를 넘길 수 없다. 넘길 경우 의미 보존 우선순위를 지키며 줄인다: 핵심 의미 > 말투 > 원문 특수기호 > 부가 수식어.
15. 의미가 달라지는 임의 창작은 금지한다.

## 출력 형식

각 대상 파일에 대해 JSON 배열 하나를 작성한다. 입력의 모든 레코드에 대해 제안하되, 정말 현재 번역이 이미 최선이라고 판단한 경우에만 생략할 수 있다.

각 객체 필드:

- `item_id`
- `source`
- `current_translation`
- `proposed_translation`
- `reason`
- `max_korean_chars`
- `proposed_chars`

`proposed_chars`는 전각 공백과 문장부호를 포함한 표시 글자 수다. `proposed_translation`은 반드시 `max_korean_chars` 이하로 작성한다.
