# Title Screen Edit Pack

GUI에서 원본 다운로드로 제공하기 위한 사용자용 PNG 묶음이다.
각 PNG는 8-column RLE 타일을 4배 확대해 만든 편집용 이미지이며, 수정 후 같은 항목에 업로드하면 자동 RLE 적용 대상이 된다.

주의: 이미지 크기와 4배 확대 비율을 유지하는 편이 가장 안전하다.

- `01_push_start__007E9158__edit_4x.png`: PUSH START / target=PRESS START는 영어 유지도 가능. 한글화 시 '시작' 또는 '눌러 시작'.
- `02_new_game__007E9404__edit_4x.png`: はじめから / target=처음부터
- `03_continue__007E95E0__edit_4x.png`: つづきから / target=이어하기
- `04_link__007E97A4__edit_4x.png`: 通信 / target=통신
- `90_logo_copyright__007E0000__advanced_edit_4x.png`: 타이틀 로고/저작권 / target=고급 항목. 로고 전체는 화면 배치 재조립 후 편집하는 편이 안전.
