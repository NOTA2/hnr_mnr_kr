# Battle Command Button Edit Pack

전투 하단 커맨드 버튼의 raw 4bpp 타일 블록이다.
각 블록은 48x16px, 6x2 tiles, 0x180 bytes이며 GUI 업로드 시 같은 오프셋에 직접 적용된다.

- `01_battle_attack__003ABF5C__edit_4x.png`: こうげき -> 공격 / 0x003ABF5C
- `02_battle_notebook__003AC0DC__edit_4x.png`: てちょう -> 수첩 / 0x003AC0DC
- `03_battle_alchemy__003AC25C__edit_4x.png`: れんせい -> 연성 / 0x003AC25C
- `04_battle_item__003AC3DC__edit_4x.png`: アイテム -> 아이템 / 0x003AC3DC
- `05_battle_escape__003AC55C__edit_4x.png`: ひっさつ -> 필살기 / 0x003AC55C
