# Resource Chunk Directory

`0x17C1E4` 부근에서 `0x083Dxxxx` 주소와 길이가 8바이트 단위로 반복되는 청크 디렉터리 후보가 확인되었다.

형식은 아래와 같다.

- `u32 rom_address`
- `u32 length`

## 현재 해석

- `0x3Dxxxx` 영역은 하나의 단일 문자열 뭉치가 아니라, 여러 리소스 청크로 분할되어 있다.
- 청크 안에는 텍스트만 있는 것이 아니라 바이너리 구조와 텍스트가 섞여 있을 수 있다.
- `battle_texts.json` 과 `material_texts.json` 은 각 청크 내부의 실제 문자열 부분만 추출한 결과다.
- `ability_texts.json` 은 여러 청크에 걸쳐 이어지는 문자열을 한 파일로 모은 것이다.
