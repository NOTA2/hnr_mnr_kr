# Data Structure Raw

이 폴더는 예전 데이터 구조 조사에서 나온 **raw evidence 묶음**이다.

포함하는 것:

- `helper_*.txt`, `helper_cluster_*.txt`
- `caller_*.txt`
- `read_*.txt`, `write_*.txt`
- `refs_*.json`
- `init_*.txt`
- 위치/슬롯/문자 helper 보조 스냅샷

이 파일들은 지금도 유효한 근거이지만, 현재 한글화 hot path 에서 매번 읽을 필요는 없다.

우선순위:

1. 먼저 상위 요약 문서나 track 문서를 본다.
2. 거기서 근거가 더 필요할 때만 이 폴더 파일을 연다.
