# 사용자 QA 안내서

이 문서는 **개발 지식이 거의 없는 사람도** 지금 프로젝트에서 무엇을 확인해야 하는지 이해할 수 있게 만든 안내서다.

목표는 간단하다.

- 무엇을 봐야 하는지 안다
- 이상한 점을 어떻게 구분하는지 안다
- 무엇을 캡처해서 전달하면 되는지 안다

이 문서만 보면 된다.  
메모리 주소나 바이너리 구조를 알 필요는 없다.

## 왜 QA가 필요한가

우리는 이미 많은 텍스트를 추출했고, 구조 분석도 거의 끝난 상태다.  
하지만 실제 게임 화면에서는 아래 같은 문제가 마지막에 남을 수 있다.

- 글자가 너무 길어서 줄이 깨짐
- 페이지가 넘겨져야 하는데 한 화면에 몰림
- 아직 일본어가 남아 있음
- 한글은 들어갔는데 이미지 속 글자는 그대로임
- 같은 화면인데 어떤 문장은 잘 나오고 어떤 문장은 안 나옴

즉 지금 QA는 “작동하나?”보다 **“실제 플레이 화면에서 자연스럽나?”** 를 확인하는 단계다.

## 지금 특히 확인해야 하는 3가지

### 1. 실제 플레이 기준 남은 일본어 확인

문서에서는 `live_playthrough_text_audit` 라고 부른다.

뜻:
- 우리가 추출한 텍스트 말고, 실제 플레이 도중 아직 일본어가 더 나오는지 보는 것

확인 예:
- 메뉴는 한글인데 특정 이벤트에서만 일본어가 나옴
- 초반은 한글인데 후반 특정 분기에서 일본어가 남아 있음
- 대사창은 한글인데 버튼 설명이나 결과 문구만 일본어

### 2. 대사창 줄수 / 페이지 넘김 확인

문서에서는 `visual_page_turn_confirmation` 이라고 부른다.

뜻:
- 텍스트 자체는 들어갔더라도, 대사창에서 **몇 줄로 보이는지**, **다음 페이지로 자연스럽게 넘어가는지** 확인하는 것

확인 예:
- 원래 2페이지여야 하는데 1페이지에 몰려서 잘림
- 줄바꿈이 어색해서 문장이 중간에서 끊김
- 다음 대사로 넘어가야 하는데 한 줄이 밑으로 밀림

### 3. 이미지에 직접 박힌 글자 확인

문서에서는 `baked_image_text_asset_review` 라고 부른다.

뜻:
- 텍스트 데이터가 아니라, **이미지 자체에 글자가 그려져 있는 경우**가 있는지 확인하는 것

확인 예:
- 타이틀 로고
- 챕터/지역 카드
- 결과 배너
- 버튼 그림 안의 글자

이건 텍스트 번역만으로는 바뀌지 않는다.  
따라서 나중에 따로 이미지 추출/수정이 필요하다.

## 사용자가 실제로 보면 되는 화면 종류

모든 화면을 다 볼 필요는 없다.  
대표 화면만 보면 된다.

### A. 시작 화면

무엇을 확인하나:
- `대륙력 / 1910년 2월 / 리젠불 마을 / 형 11세 동생 10세`
- 글자가 잘리지 않는지
- 줄 위치가 맞는지
- 그림자/본문 색이 정상인지

이상한 경우 예:
- `마을`이 사라짐
- 한 줄이 아래로 밀림
- 그림자와 본문이 반대로 보임

### B. 메뉴 / 세이브 / 시스템 문구

무엇을 확인하나:
- 짧은 안내문
- 확인/취소 계열 문구
- 저장 관련 경고/안내

이상한 경우 예:
- 짧은 문구인데 한 줄이 넘침
- 메뉴 문구 일부가 일본어로 남음
- 줄바꿈이 생기면 안 되는 곳에서 줄이 갈라짐

### C. 월드맵 / 지역명

무엇을 확인하나:
- 지역명이 정해진 위치에 잘 들어가는지

이상한 경우 예:
- 글자가 길어서 위치가 삐끗함
- 일부만 보임
- 다른 UI와 겹침

### D. 대사창

무엇을 확인하나:
- 한 줄 길이
- 한 화면 안의 줄 수
- 다음 페이지로 넘어가는 흐름
- 같은 화자처럼 보이는 대사가 계속 자연스럽게 이어지는지

이상한 경우 예:
- 문장이 너무 길어 마지막 글자가 사라짐
- 페이지가 넘어가야 하는데 아래로 밀림
- 줄바꿈 위치가 너무 어색함
- 같은 장면인데 어떤 줄은 잘 나오고 어떤 줄은 깨짐

### E. 이미지 글자 후보

무엇을 확인하나:
- 텍스트 데이터로 바뀌지 않는 글자
- 로고, 카드, 배너, 그림 속 라벨

이상한 경우 예:
- 대사창은 한글인데 챕터 카드는 일본어 그대로
- 결과 배너만 일본어
- 타이틀 메뉴 글자만 일본어

## 문제가 생겼을 때 분류하는 법

제일 중요한 건 **정확한 원인 분석**이 아니라, **증상을 잘 분류해서 전달하는 것**이다.

아래 분류 중 하나로 보내주면 충분하다.

### 1. 일본어 잔존

뜻:
- 한글화됐어야 할 곳에 일본어가 그대로 남아 있음

예:
- 메뉴 문구 일부
- 이벤트 대사 일부
- 배너/카드 텍스트

### 2. 줄바꿈/페이지 문제

뜻:
- 문장은 번역됐지만 화면 배치가 이상함

예:
- 줄이 너무 많이 들어감
- 마지막 글자가 잘림
- 페이지 넘김이 꼬임

### 3. 폰트 표시 문제

뜻:
- 글자 모양이나 그림자/색이 이상함

예:
- 너무 흐림
- 그림자가 반대로 보임
- 글자가 일부 빠짐
- 받침이나 세로획이 깨짐

### 4. 이미지 텍스트 문제

뜻:
- 텍스트 데이터가 아니라 이미지 속 글자라서 안 바뀐 것 같음

예:
- 로고
- 카드
- 배너
- 버튼 그림 글자

## 문제를 전달하는 가장 좋은 방법

아래 4개만 있으면 충분하다.

1. 스크린샷
2. 어디에서 나온 화면인지
3. 무엇이 이상한지 한 줄 설명
4. 가능하면 “원래 기대한 모습”

예시:

```text
화면: 초반 시작 카드
문제: '리젠불 마을'에서 '마을'이 안 보임
기대: 한 줄 전체가 보여야 함
첨부: 스크린샷
```

또는:

```text
화면: 대사창, 에드 초상화가 나오는 장면
문제: 2번째 줄이 아래로 밀려서 페이지가 안 넘어감
기대: 2페이지로 넘어가야 할 것 같음
첨부: 스크린샷
```

## 사용자가 굳이 신경 안 써도 되는 것

아래는 개발 쪽에서 처리하는 영역이다.

- 메모리 주소
- 포인터
- 제어코드
- 압축 여부
- 이미지 포맷
- 어떤 family 구조인지

이건 내가 처리한다.  
사용자는 **“어디 화면에서, 무엇이, 어떻게 이상한지”** 만 알려주면 된다.

## 추천 QA 순서

한 번에 다 보지 말고 이 순서로 보면 된다.

1. 시작 화면
2. 타이틀/메뉴/세이브 문구
3. 월드맵 지역명
4. 초반 대사창 장면
5. 일본어가 남은 UI/배너/카드

이 순서가 좋은 이유:
- 초반에 바로 볼 수 있다
- 문제 재현이 쉽다
- 구조별 대표 화면을 빠르게 커버할 수 있다

## 지금 단계에서의 현실적인 목표

지금 QA의 목표는 “게임 전체를 완벽히 끝낸다”가 아니다.

우선은:
- 폰트가 자연스럽게 보이는지
- 대표적인 텍스트 구조가 깨지지 않는지
- 아직 안 바뀐 일본어가 어떤 종류인지

이 세 가지만 잘 잡으면 된다.

그러면 그다음부터는
- 번역 진행
- 자동 삽입
- 이미지 교체

를 훨씬 안정적으로 밀 수 있다.
