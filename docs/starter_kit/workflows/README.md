# Starter Kit Workflows

These workflow notes turn the retrospective into a repeatable operating order.

- `bootstrap_sequence.md`: what to create in the first days of a new GBA
  localization project.
- `cleanup_sequence.md`: how to clean a late-stage project without losing active
  QA inputs or retrospective evidence.

The current project remains more complex than this skeleton. Do not force the
active repo to match these paths during final QA; use this folder to prepare the
next project.
