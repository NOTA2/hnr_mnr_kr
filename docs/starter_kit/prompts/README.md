# Starter Kit Prompts

This folder contains reusable prompt material for a future GBA localization
agent. Keep it project-neutral:

- no ROM names;
- no extracted project text;
- no local machine paths;
- no raw session logs;
- no claims that only apply to one game.

Start from `agent_seed_prompt.md`, then add project-specific context in the new
repo's own `docs/session_start.md` or equivalent handoff file.
