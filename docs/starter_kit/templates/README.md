# Starter Kit Templates

These files are copyable starting points for a new GBA localization repo.

- `project_config.example.json`: minimal project configuration matching
  `../schemas/project_config.schema.json`.
- `gitignore.gba-localization.example`: starter ignore policy for ROMs, saves,
  patches, generated workbenches, and temporary files.
- `local_runtime_artifacts_matrix.template.md`: local ROM/save/savestate keep
  matrix.
- `generated_workbench_retention.template.md`: generated-output retention and
  deletion decision template.

Templates should stay free of this project's ROM names, offsets, text strings,
image paths, and local machine paths.
